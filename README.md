# SIGNAL // Basheer Almajdoby

A tactical, Rainbow Six Siege-inspired social profile page.

## Publish It

This repository includes a GitHub Pages workflow. For a link anyone can open, make the repository public (or use a GitHub plan that supports Pages for private repositories), then open **Settings > Pages** and set the source to **GitHub Actions**. Every push to `main` will deploy the site.

The public address will be:

`https://basheerluigi007-star.github.io/kabab/`

The header share button uses the native share sheet on mobile and copies the public URL on desktop.
